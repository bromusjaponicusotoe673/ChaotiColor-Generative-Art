## ⚙️ How to Generate Art

The interface contains three primary modes for generating patterns. Each mode creates a different type of chaotic behavior.

### Setting the Palette
The software uses vibrant color palettes to define the output. You can cycle through existing presets by clicking the cycle button. The colors update instantly on your screen. These colors mimic professional dye charts used in the textile industry.

### Adjusting Modes
There are three unique modes available:
*   Static Growth: This mode builds a design layer by layer. It creates stable patterns useful for repeating prints.
*   Dynamic Chaos: This mode causes the pattern to shift and change over time. Use this mode if you want to experiment with flow and movement.
*   Grid Flow: This mode forces the patterns into a structured layout. It works best for apparel design where symmetry matters.

### Saving Your Work
After you find a pattern, click the Save button. The program generates an image file in PNG format. You can use this file for t-shirt design, fabric printing, or digital projects.

## 🎯 Best Practices for Textile Design

Generative art differs from traditional drawing. Because the patterns evolve based on rules, you should embrace the small variations between each run. If you design for t-shirts, choose a high-contrast palette to ensure the pattern shows well on fabric. Keep the pattern density low for smaller prints and high for large items like posters or blankets.

Test your output on different color backgrounds. Since the program allows you to change palettes, try a dark background for evening wear or a light background for casual items. The modular nature of cellular automata means you can tile these images together to create larger, seamless patterns for repeating fabric prints.

## 💡 Customizing the Experience

While the software features presets, you can influence the output by changing the grid size. Smaller grids create chunky, blocky designs. Larger grids produce intricate, fine-line patterns. Experiment with these settings to match your specific style. If the patterns move too fast, use the speed slider to slow down the growth rate. This allows you to capture specific moments in the generation process that look particularly balanced or artistic.
